## 1. Challenge Overview

The challenge provides an encrypted flag along with the internal parameters of a 64-bit Linear Feedback Shift Register (LFSR):
- **Register Length:** $n = 64$ bits
- **Initial State:** 64-element binary vector $S_0 = [s_0, s_1, \dots, s_{63}]$
- **Feedback Taps:** Taps located at indices $[63, 61, 60, 58]$
- **Ciphertext:** 48 hex-encoded bytes (`8f0e6d0f5b0dc1db...`)

---

## 2. Mathematical Model of the LFSR

A Fibonacci LFSR computes a feedback bit as the linear combination (XOR) over $\mathbb{F}_2$ of designated tap positions:
$$s_{t+n} = \sum_{i \in \text{Taps}} s_{t+i} \pmod 2$$
The characteristic feedback polynomial is represented as:
$$P(x) = x^{64} \oplus x^{63} \oplus x^{61} \oplus x^{60} \oplus x^{58} \oplus 1$$

The keystream sequence $Z = (z_0, z_1, z_2, \dots)$ is generated by clocking the shift register:
1. Output bit $z_t = s_t$.
2. Shift the register by 1 bit.
3. Insert the newly computed feedback bit at the input.
4. The keystream is grouped into 8-bit bytes and XORed with the plaintext flag $M$:
   $$C_i = M_i \oplus K_i$$

---

## 3. Cryptanalysis & Known-Plaintext Alignment

Because the flag format is known to start with `picoCTF{`, the first 64 keystream bits can be derived via known-plaintext attack:
$$K_{\text{known}}[0:64] = C[0:64] \oplus \text{"picoCTF{"}$$
Comparing $K_{\text{known}}$ against the initial state vectors determines:
- Bit ordering within bytes (Most Significant Bit vs Least Significant Bit first).
- Shift direction (left-shift versus right-shift register architecture).
- Pre-clocking vs post-clocking stream alignment.

Reconstructing the exact register clocking loop allows full recovery of the remaining 40 plaintext characters.
