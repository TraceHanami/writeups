# Husk — Reverse Engineering Writeup

**Category:** Reverse Engineering  
**Challenge:** Husk (`rev_husk.zip`)  
**Flag:** `zdk{tHe_AnTlD3bU6_wAs_The_decryP7LoN_Key}`

---

## 1. Challenge Overview

The challenge archive `rev_husk.zip` contains a single stripped 64-bit ELF binary named `husk`.

```text
File: husk
Arch: ELF 64-bit LSB pie executable, x86-64
Security:
  RELRO:    Partial RELRO
  Stack:    No canary found
  NX:       NX enabled
  PIE:      PIE enabled
```

Usage:
```bash
./husk <flag>
```
If the correct 41-character flag is supplied, it prints `Correct!`. Otherwise, it outputs `Nope`.

---

## 2. Binary Analysis & Reverse Engineering

Disassembly of `main` reveals four key phases:

### A. Anti-Debugging as Key Material Generation
The program performs several environment and anti-debugging checks. Instead of immediately aborting on detection, it uses the result of each check to compute four 32-bit values that form a 16-byte cryptographic key:

1. **`ptrace(PTRACE_TRACEME, ...)` Check**:
   - `ptrace(0, 0, 0, 0)` returns `0` if not traced under a debugger.
   - `k0 = ptrace(...) ^ 0x1337c0de` $\rightarrow$ `0x1337c0de`.
2. **`/proc/self/status` `TracerPid` Check**:
   - Parses `TracerPid:` from `/proc/self/status`. If untraced, `TracerPid == 0`.
   - `k1 = TracerPid ^ 0xb16b00b5` $\rightarrow$ `0xb16b00b5`.
3. **RDTSC Execution Timing Check**:
   - Measures CPU clock cycles across a small busy loop. If elapsed cycles $< 30,000,000$, flag is `0`.
   - `k2 = (0) ^ 0xfeedface` $\rightarrow$ `0xfeedface`.
4. **`LD_PRELOAD` Environment Check**:
   - Calls `getenv("LD_PRELOAD")`. When not set (`NULL` / 0), `k3 = 0 ^ 0xcafebabe` $\rightarrow$ `0xcafebabe`.

The resulting 16-byte key in little-endian is:
$$\text{key} = \text{0x1337c0de } \|\text{ 0xb16b00b5 } \|\text{ 0xfeedface } \|\text{ 0xcafebabe}$$

---

### B. Target Ciphertext Generation (RC4)
1. The binary loads 41 bytes from two `.rodata` tables:
   $$\text{buf40}[i] = \text{table1}[(i \times 17) \pmod{41}] \oplus \text{table2}[i \pmod{16}]$$
2. It initializes standard **RC4 (KSA + PRGA)** using the 16-byte key obtained above and encrypts `buf40` into `buf140`.
3. `buf140` serves as the final target state that the transformed flag must match.

---

### C. Input Pre-Whitening (LCG PRNG)
The 41-byte input `argv[1]` is XORed with a 41-byte pseudo-random stream generated by a Linear Congruential Generator:
- $\text{seed}_0 = \text{0x1234abcd}$
- $\text{seed}_{n+1} = (\text{seed}_n \times \text{0x41c64e6d} + \text{0x3039}) \pmod{2^{32}}$
- $\text{stream}[n] = (\text{seed}_{n+1} \gg 24) \ \&\ \text{0xff}$

$$\text{state}_0 = \text{argv}[1] \oplus \text{stream}$$

---

### D. 6-Round Bijective State Transformation
`state` undergoes 6 sequential rounds ($r \in [0, 5]$). Each round consists of three strictly reversible steps:

1. **Forward Running-State Diffusion**:
   - For $i = 0 \dots 40$:
     $$\text{sh}_1 = ((r + i) \bmod 7) + 1, \quad \text{sh}_2 = ((r_{11} + i) \bmod 7) + 1$$
     $$\text{val} = \text{ROL}_8((\text{state}[i] + i \cdot \text{0x1d} + r_{10}) \bmod 256, \text{sh}_1)$$
     $$\text{edi} = \text{ROL}_8(\text{edi}, \text{sh}_2) \oplus \text{val}$$
     $$\text{scratch}[i] = \text{edi}$$

2. **Backward Running-State Substitution**:
   - Starting from $i = 40$ down to $0$:
     $$\text{sh}_1 = ((r_{13} + i) \bmod 7) + 1, \quad \text{sh}_2 = (r_8 \bmod 7) + 1$$
     $$\text{temp} = \text{ROL}_8(\text{eax}, \text{sh}_1) \oplus \text{scratch}[i]$$
     $$\text{out}[i] = \text{ROL}_8((\text{temp} + \text{ebp}) \bmod 256, \text{sh}_2)$$
     $$\text{eax} = \text{out}[i], \quad \text{ebp} = (\text{ebp} - \text{0x11}) \bmod 256, \quad r_8 = r_8 - 3$$

3. **Index Permutation**:
   - For $i = 0 \dots 40$:
     $$\text{permuted}[(r \cdot 5 + i \cdot 7) \bmod 41] = \text{out}[i]$$

After 6 rounds, the state must equal the target ciphertext `buf140`.

---

## 3. Solution & Inversion Script

Because every operation (modular permutation, running-state rotations/additions, LCG keystream) is deterministic and bijective, we can invert the rounds in reverse ($r = 5 \dots 0$) to recover the flag.

### `solve.py`

```python
import struct

def rol8(val, r):
    r = r % 8
    return ((val << r) | (val >> (8 - r))) & 0xff

def ror8(val, r):
    r = r % 8
    return ((val >> r) | (val << (8 - r))) & 0xff

def get_target():
    key = struct.pack("<IIII", 0x1337c0de, 0xb16b00b5, 0xfeedface, 0xcafebabe)

    r10_data = bytes.fromhex("1f514fbaebb7352b70fbe6b041fc56512b6f45731287e647ac9d518efb89e1dbbbd09ab6a024613629")
    r9_data = bytes.fromhex("7319a6d42b8e55c10fb7623de8944a20")

    buf40 = bytearray(41)
    ecx = 0
    for rdx in range(41):
        idx = ecx % 41
        ecx += 0x11
        buf40[rdx] = r10_data[idx] ^ r9_data[rdx & 0xf]

    S = list(range(256))
    j = 0
    for i in range(256):
        j = (j + S[i] + key[i % 16]) & 0xff
        S[i], S[j] = S[j], S[i]

    buf140 = bytearray(41)
    i = 0
    j = 0
    for idx in range(41):
        i = (i + 1) & 0xff
        j = (j + S[i]) & 0xff
        S[i], S[j] = S[j], S[i]
        k = S[(S[i] + S[j]) & 0xff]
        buf140[idx] = buf40[idx] ^ k

    return buf140

def lcg_bytes():
    seed = 0x1234abcd
    res = bytearray(41)
    for i in range(41):
        seed = (seed * 0x41c64e6d + 0x3039) & 0xffffffff
        res[i] = (seed >> 24) & 0xff
    return res

def inverse_round(out3, round_idx, r9d, r10d, r11d, r13d, r14d):
    # Inverse Step 3: Permutation
    out2 = bytearray(41)
    ecx = round_idx * 5
    for i in range(41):
        pos = ecx % 41
        ecx += 7
        out2[i] = out3[pos]

    # Inverse Step 2: Backward running-state
    ebp_list = {}
    r8d_list = {}
    cur_ebp = r14d & 0xff
    cur_r8d = round_idx + 0x78
    for rdi in range(40, -1, -1):
        ebp_list[rdi] = cur_ebp
        r8d_list[rdi] = cur_r8d
        cur_ebp = (cur_ebp - 0x11) & 0xff
        cur_r8d -= 3

    scratch = bytearray(41)
    eax = (13 * r13d ^ 0x5c) & 0xff
    for rdi in range(40, -1, -1):
        eax_prev = eax
        sh1 = ((r13d + rdi) % 7) + 1
        sh2 = (r8d_list[rdi] % 7) + 1
        ebp = ebp_list[rdi]
        
        temp = ror8(out2[rdi], sh2)
        temp = (temp - ebp) & 0xff
        scratch[rdi] = temp ^ rol8(eax_prev, sh1)
        eax = out2[rdi]

    # Inverse Step 1: Forward running-state
    buf = bytearray(41)
    edi = (r9d ^ 0xffffffa5) & 0xff
    r8d = 0
    for rdx in range(41):
        sh2 = ((r11d + rdx) % 7) + 1
        edi_prev = edi
        edi_next = scratch[rdx]
        val = edi_next ^ rol8(edi_prev, sh2)
        sh1 = ((round_idx + rdx) % 7) + 1
        raw = ror8(val, sh1)
        buf[rdx] = (raw - r8d - r10d) & 0xff
        r8d = (r8d + 0x1d)
        edi = edi_next

    return buf

def solve():
    round_params = []
    r9d = 0
    r10d = 0x13
    r11d = 0
    r13d = 0
    r14d = 0x15

    for r in range(6):
        round_params.append((r, r9d, r10d, r11d, r13d, r14d))
        r9d = (r9d + 0x3d)
        r14d = (r14d + 0x2b)
        r13d = (r13d + 3)
        r10d = (r10d + 0x47)
        r11d = (r11d + 2)

    cur = get_target()
    for r, r9, r10, r11, r13, r14 in reversed(round_params):
        cur = inverse_round(cur, r, r9, r10, r11, r13, r14)

    lcg = lcg_bytes()
    flag = bytes([b ^ k for b, k in zip(cur, lcg)]).decode()
    print("Flag:", flag)

if __name__ == "__main__":
    solve()
```
