# ASIS CTF — new_less_is_more (Crypto) Writeup

## Challenge Overview

In this challenge, we are provided with:
- `challenge.py`: The implementation of a zero-knowledge identification / signature-like scheme based on code-based cryptography (alternating/generalized Reed-Solomon / Cauchy-like generator matrix code equivalence) combined with a tree-based commitment scheme.
- `flag.enc`: A pickled and zlib-compressed archive containing:
  - `pub`: Parameters ($P=827, N=548, K=274, T=345, W=75$, etc.), the base generator matrix $G$, and 17 public matrices (7 real secret keys + 10 junk/decoy keys, shuffled).
  - `records`: 5,963 interaction records generated by `Box.one()`.
  - `sealed`: 54-byte XOR-encrypted flag.

The goal is to recover the 7 real secret keys $(p_k, d_k)_{k=0}^6$, derive the SHAKE-256 keystream, and decrypt the flag.

---

## 1. Vulnerability Analysis

### A. Cover Tree State Leakage
In `Box.one()`, the prover creates a binary tree of seeds rooted at `root` and computes:
- The challenge vector $b = \text{chal}(cmt, salt, msg) \in \{0, \dots, 7\}^T$.
- An indicator vector $f$, initially set to $f_i = \mathbb{I}(b_i \neq 0)$.

Normally, $f_i = 1$ whenever $b_i \neq 0$ to prevent the binary tree cover (`cover(tr, depth, f)`) from revealing any tree node covering leaf index $i$.

However, there is an intentional flaw in the state update logic:
```python
target = (37 * serial + 11) % T
if int.from_bytes(hashlib.sha256(b'v' + root).digest()[:2], 'big') % 100 < 72:
    f[target] = self.state[target]
self.state = f
```
With 72% probability, $f[\text{target}]$ is overwritten by `self.state[target]`. If `self.state[target]` was previously $0$, $f[\text{target}]$ becomes $0$ even if $b[\text{target}] \neq 0$.

When $f[\text{target}] = 0$, the `cover` algorithm outputs an internal ancestor node covering `target`. By expanding this ancestor node downwards (`sha256(b'l' + s)` and `sha256(b'r' + s)`), we can recover the true `leaf[target]` seed!

### B. Unmasking the Responses
Each record contains:
1. `path`: Tree nodes masked with `token(cmt, u) = u ^ (sha256(b'm' + cmt)[:2] & 1023)`.
2. `rsp`: Pairs of `[label(cmt, leaf_seed), bits(inv_p[v])]` where $v = \text{take}(\text{leaf\_seed}, b'n', N, K)$.

Because `cmt` is known for every record, we can:
1. Unmask all tree node indices in `path`.
2. Propagate seeds down from all internal nodes ($u < 512$) to reconstruct leaf seeds $\text{leaf}[i]$.
3. For any $i$ where $b_i = x > 0$ and $\text{leaf}[i]$ is recovered, lookup $\text{label}(cmt, \text{leaf}[i])$ in `rsp` to obtain the response bitmap.

---

## 2. Permutation Recovery via Correlation

For a query $i$ with challenge class $x \in \{1, \dots, 7\}$:
- The prover generated subset $v = \text{take}(\text{leaf}[i], b'n', N, K) \subset \{0, \dots, N-1\}$.
- The response bitmap is $S = \{ p_{x-1}^{-1}(j) : j \in v \}$, meaning:
  $$\text{pos} \in S \iff p_{x-1}(\text{pos}) \in v$$

Notice that with $\approx 14\%$ probability, the prover corrupted a response with a random subset (`bits(take(root, b'z', N, K))`). However, because we have $\sim 70-95$ samples per key class, we can determine each $p_{x-1}(\text{pos})$ by voting across all samples:

$$\text{score}(\text{pos}, y) = \sum_{\text{sample } (v, S)} \mathbb{I}((\text{pos} \in S) == (y \in v))$$

The true mapping $y = p(\text{pos})$ achieves a score of $\approx 93\%$, whereas incorrect mappings achieve $\approx 50\%$. Selecting $\arg\max_y \text{score}(\text{pos}, y)$ perfectly recovers all 548 elements of $p_k$ for every $k \in \{0, \dots, 6\}$.

---

## 3. Scaling Vector $d$ Reconstruction

The public key matrix $M \in \mathbb{F}_P^{K \times N}$ is the row-reduced echelon form (RREF) of:
$$M = \text{RREF}\left( G \cdot P_{\pi} \cdot D^{-1} \right)$$
where $G \in \mathbb{F}_P^{K \times N}$ is the Cauchy base matrix, $P_{\pi}$ is the permutation matrix for $p$, and $D = \text{diag}(d_0, d_1, \dots, d_{N-1})$.

Thus, there exists an invertible matrix $A \in \mathbb{F}_P^{K \times K}$ such that for all columns $c \in \{0, \dots, N-1\}$:
$$d_c \cdot M_{*, c} = A \cdot G_{*, p[c]} \pmod P$$

Let the $K$ pivot columns of $M$ be $C = (c_0, c_1, \dots, c_{K-1})$. Since $M_{*, C} = I_K$:
$$A = D_C \cdot (G_{*, p[C]})^{-1}$$

Substituting $A$ back into the column equations gives:
$$\frac{d_{c_i}}{d_{c_j}} = \frac{M_{i, c} \cdot v_{c}[j]}{M_{j, c} \cdot v_{c}[i]} \pmod P \quad \text{where } v_c = (G_{*, p[C]})^{-1} \cdot G_{*, p[c]}$$

Using these pairwise ratios across multiple columns $c$, we reconstruct $D_C = \text{diag}(d_{c_0}, \dots, d_{c_{K-1}})$ (up to an overall scalar factor, which is normalized by `inv(d[0])`). We then solve for all $d_c$, match $p_k$ to the corresponding public matrix in `pub`, and verify the matrix equivalence.

## 4. Full Solve Script

```python
#!/usr/bin/env python3
import hashlib
import pickle
import struct
import zlib
from collections import defaultdict
from challenge import P, N, K, T, W, REAL, SLOTS, DECOY, chal, token, label, inv, pack_key, red, take

def solve():
    with open('flag.enc', 'rb') as f:
        f.read(12)
        data = pickle.loads(zlib.decompress(f.read()))

    records = data['records']
    pub_matrices = data['pub']['pub']
    G = data['pub']['g']
    sealed = data['sealed']

    depth = 0
    z = 1
    while z < T:
        z <<= 1
        depth += 1
    base0 = 1 << depth

    def bits_to_set(bs):
        val = int.from_bytes(bs, 'little')
        return {x for x in range(N) if (val >> x) & 1}

    # Step 1: Recover valid (v, S) pairs from records
    samples_by_key = defaultdict(list)
    for r in records:
        cmt = r['cmt']
        salt = r['salt']
        msg = r['msg']
        b = chal(cmt, salt, msg)
        mask = int.from_bytes(hashlib.sha256(b'm' + cmt).digest()[:2], 'big') & 1023

        # Expand cover tree
        tree_nodes = {}
        for tok, seed in r['path']:
            u = tok ^ mask
            if u < base0:
                tree_nodes[u] = seed

        for i in range(1, base0):
            if i in tree_nodes:
                s = tree_nodes[i]
                l_seed = hashlib.sha256(b'l' + s).digest()
                r_seed = hashlib.sha256(b'r' + s).digest()
                if 2 * i not in tree_nodes:
                    tree_nodes[2 * i] = l_seed
                if 2 * i + 1 not in tree_nodes:
                    tree_nodes[2 * i + 1] = r_seed

        rsp_dict = {lbl: bs for lbl, bs in r['rsp']}

        for i in range(T):
            if b[i] != 0:
                u = base0 + i
                if u in tree_nodes:
                    leaf_seed = tree_nodes[u]
                    lbl = label(cmt, leaf_seed)
                    if lbl in rsp_dict:
                        key_idx = b[i] - 1
                        bs = rsp_dict[lbl]
                        v = set(take(leaf_seed, b'n', N, K))
                        s_out = bits_to_set(bs)
                        if len(s_out) == K:
                            samples_by_key[key_idx].append((v, s_out))

    # Step 2 & 3: Recover permutation p and scaling factors d for each key
    recovered_keys = []
    for k in range(REAL):
        samples = samples_by_key[k]
        scores = [[0] * N for _ in range(N)]
        for v, s_out in samples:
            for x in range(N):
                x_in = x in s_out
                for y in range(N):
                    if x_in == (y in v):
                        scores[x][y] += 1

        p = [max(range(N), key=lambda y: scores[x][y]) for x in range(N)]

        best_d = None
        for M in pub_matrices:
            pivots = []
            r = 0
            for c in range(N):
                if r < K and M[r][c] == 1 and all(M[i][c] == 0 for i in range(K) if i != r):
                    pivots.append(c)
                    r += 1
            if len(pivots) != K:
                continue

            G_piv = [[G[row][p[pivots[col]]] for col in range(K)] for row in range(K)]
            aug = [G_piv[row] + [int(row == col) for col in range(K)] for row in range(K)]
            aug_red = red(aug)
            if any(aug_red[row][row] != 1 for row in range(K)):
                continue
            G_piv_inv = [aug_red[row][K:] for row in range(K)]

            d_piv = [None] * K
            d_piv[0] = 1
            consistent = True

            for c in range(N):
                v_c = [sum(G_piv_inv[row][col] * G[col][p[c]] for col in range(K)) % P for row in range(K)]
                for i in range(K):
                    if M[i][c] != 0 and v_c[i] != 0:
                        for j in range(K):
                            if M[j][c] != 0 and v_c[j] != 0:
                                ratio = (M[j][c] * v_c[i] * inv((M[i][c] * v_c[j]) % P)) % P
                                if d_piv[i] is not None:
                                    val_j = (d_piv[i] * ratio) % P
                                    if d_piv[j] is not None and d_piv[j] != val_j:
                                        consistent = False; break
                                    d_piv[j] = val_j
                                elif d_piv[j] is not None:
                                    val_i = (d_piv[j] * inv(ratio)) % P
                                    if d_piv[i] is not None and d_piv[i] != val_i:
                                        consistent = False; break
                                    d_piv[i] = val_i
                        if not consistent: break
                if not consistent: break

            if not consistent or any(x is None for x in d_piv):
                continue

            d = [0] * N
            for c in range(N):
                v_c = [sum(G_piv_inv[row][col] * G[col][p[c]] for col in range(K)) % P for row in range(K)]
                for i in range(K):
                    if M[i][c] != 0 and v_c[i] != 0:
                        d[c] = (d_piv[i] * v_c[i] * inv(M[i][c])) % P
                        break

            if red([[(G[i][p[j]] * inv(d[j])) % P for j in range(N)] for i in range(K)]) == M:
                best_d = d
                break

        recovered_keys.append((p, best_d))

    pad = hashlib.shake_256(b'o' + pack_key(recovered_keys)).digest(len(sealed))
    flag = bytes(x ^ y for x, y in zip(sealed, pad))
    print(f"Decrypted Flag: {flag.decode()}")

if __name__ == '__main__':
    solve()
```
