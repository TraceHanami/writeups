## 1. Challenge Overview

We are given an encryption script [`linchan.py`](linchan.py) and a compressed payload `output.txt`.

The system parameters and construction are:
- $32 \times 32$ matrices over $\mathbb{F}_2$ (represented as 32-bit integer arrays).
- Subspace dimensions $m \in \{16, 17, 18\}$ with multiplicities $c \in \{2, 2, 1\}$, totaling 5 secret keys $S_k \in \text{GL}(32, \mathbb{F}_2)$.
- For each secret transformation $S \in \text{GL}(32, \mathbb{F}_2)$:
  1. A subspace $C$ of dimension $m$ is generated. The first two basis elements $H_1, H_2$ are generated as rank-25 matrices ($A \cdot B$ with $A \in \mathbb{F}_2^{32 \times 25}$ and $B \in \mathbb{F}_2^{25 \times 32}$). The remaining $m - 2$ basis elements are full-rank random matrices.
  2. The conjugate subspace $D = S C S^{-1} = \{ S A S^{-1} \mid A \in C \}$ is created.
  3. Both $C$ and $D$ are randomized with a change of basis ($\_u(m)$) and optionally transposed ($\_t(\cdot)$) with 50% probability via the obfuscator $\_o(\cdot)$.
  4. 34 dummy random subspaces of dimension $m$ (with full rank basis elements) are added per dimension.
- All 112 boxes are shuffled and saved in `output.txt`.
- The list of secret matrices $K = [S_1, \dots, S_5]$ derives a 256-bit key via `SHAKE-256`, which encrypts the flag using `ChaCha20Poly1305`.

## 2. Mathematical Analysis & Vulnerability

### 2.1 Low Rank Invariant
A random $32 \times 32$ binary matrix has rank $\le 25$ with probability:
$$\mathbb{P}(\text{rank}(M) \le 25) \approx 2^{-(32-25)^2} = 2^{-49} \approx 1.77 \times 10^{-15}$$
In a dummy subspace of dimension $m \le 18$, the number of non-zero linear combinations is at most $2^{18} \approx 2.6 \times 10^5$.
The expected number of low-rank matrices in any dummy box is:
$$2.6 \times 10^5 \times 2^{-49} \approx 4.6 \times 10^{-10} \approx 0$$

However, in every genuine box $C$ or $D$:
- There is a 2-dimensional subspace containing matrices of rank $\le 25$.
- Specifically, the two rank-25 generators $H_1, H_2$ have rank exactly 25.
- Conjugation ($S H S^{-1}$), basis change, and transposition ($H^T$) preserve the rank of matrices.

Thus, we can reliably distinguish the 10 genuine boxes from the 102 dummy boxes simply by checking the ranks of all $2^m$ linear combinations in each subspace using Gray-code iteration.

---

### 2.2 Reconstructing the Similarity Matrix $S$

For a genuine box pair $(C, D)$ generated by secret transformation $S$:
Let $H_{C, 1}, H_{C, 2}$ be the two rank-25 matrices in box $C$, and $H_{D, 1}, H_{D, 2}$ be the two rank-25 matrices in box $D$.

Under the relation:
$$H_D = S H_C S^{-1} \implies S H_C + H_D S = 0$$

Considering potential transpositions from the obfuscator $\_o(\cdot)$ and permutations of the generator pair:
$$S H_C' + H_D' S = 0 \quad (\text{mod } 2)$$
where $H_C' \in \{H_C, H_C^T\}$ and $H_D' \in \{H_D, H_D^T\}$.

For the entry-wise unknown matrix $S \in \mathbb{F}_2^{32 \times 32}$ (1024 variables):
- $S H_C' + H_D' S = 0$ yields $32 \times 32 = 1024$ linear equations over $\mathbb{F}_2$.
- Two generators give $2 \times 1024 = 2048$ linear equations.
- Gaussian elimination over $\mathbb{F}_2$ finds a unique non-trivial invertible solution $S \in \text{GL}(32, \mathbb{F}_2)$.

---

### 2.3 Invariance of Canonical Representation

The key derivation function in `linchan.py` uses:
```python
def _f(S):
    T = _i(S)
    return min(_p(S), _p(T), _p(_t(S)), _p(_t(T)))
```
Notice that $\{S, S^{-1}, S^T, S^{-T}\}$ all yield the exact same output from `_f(S)`. Any equivalent transformation recovered between the transposed/swapped subspaces automatically normalizes to the true secret key.

## 3. Exploit Implementation

### Step 1: Scan all boxes for rank-25 matrices
Using a fast C helper or Python script with Gray codes, we find that:
- $m=16$: Boxes `49, 60, 82, 86` are genuine.
- $m=17$: Boxes `1, 47, 92, 106` are genuine.
- $m=18$: Boxes `32, 44` are genuine.

### Step 2: Match pairs and recover $S$
Setting up the system $S A + B S = 0$ over $\mathbb{F}_2$:
- Pair `(49, 60)` $\implies S_1$
- Pair `(82, 86)` $\implies S_2$
- Pair `(1, 92)` $\implies S_3$
- Pair `(47, 106)` $\implies S_4$
- Pair `(32, 44)` $\implies S_5$

### Step 3: Decrypt
Derive `key = SHAKE256(b"linchan-v2/key\0" + sorted(_f(S)))` and decrypt `ct` using `ChaCha20Poly1305` with AAD `linchan/v2`.

## 4. Full Solve Script

```python
import json, base64, zlib, itertools, hashlib
import numpy as np
from cryptography.hazmat.primitives.ciphers.aead import ChaCha20Poly1305

_n = 32
_z = b"linchan/v2"

def _p(A):
    return b"".join(int(x).to_bytes(4, "little") for x in A)

def _t(A):
    R = [0] * _n
    for i, x in enumerate(A):
        while x:
            b = x & -x
            R[b.bit_length() - 1] |= 1 << i
            x ^= b
    return R

def _i(A):
    R = [x | (1 << (_n + i)) for i, x in enumerate(A)]
    for i in range(_n):
        j = next((j for j in range(i, _n) if (R[j] >> i) & 1), None)
        if j is None: raise ValueError
        R[i], R[j] = R[j], R[i]
        for j in range(_n):
            if j != i and ((R[j] >> i) & 1):
                R[j] ^= R[i]
    return [x >> _n for x in R]

def _r(A):
    P = {}
    for x in A:
        while x:
            i = x.bit_length() - 1
            if i in P: x ^= P[i]
            else: P[i] = x; break
    return len(P)

def _f(S):
    T = _i(S)
    return min(_p(S), _p(T), _p(_t(S)), _p(_t(T)))

def _k(S):
    X = b"".join(sorted(_f(A) for A in S))
    return hashlib.shake_256(b"linchan-v2/key\0" + X).digest(32)

data = json.loads(zlib.decompress(base64.b85decode(open('output.txt').read())))
boxes = data['boxes']
ct_all = base64.b85decode(data['ct'])
nonce, ciphertext = ct_all[:12], ct_all[12:]

def parse_box(bi):
    b = boxes[bi]
    m, raw = b['m'], base64.b85decode(b['x'])
    mats = []
    for i in range(m):
        chunk = raw[i*128:(i+1)*128]
        mats.append([int.from_bytes(chunk[j*4:(j+1)*4], 'little') for j in range(32)])
    return m, mats

def get_mat_from_mask(basis, mask):
    res = [0]*32
    for i in range(len(basis)):
        if (mask >> i) & 1:
            for r in range(32):
                res[r] ^= basis[i][r]
    return res

genuine_info = {
    1: [115212, 85611], 32: [258067, 194486], 44: [63116, 209023],
    47: [113913, 81473], 49: [55979, 54049],   60: [25490, 54229],
    82: [21435, 23963],  86: [32017, 55669],   92: [94039, 78842],
    106: [100056, 112991],
}

def to_np_mat(mat):
    arr = np.zeros((32, 32), dtype=np.uint8)
    for i in range(32):
        for j in range(32):
            if (mat[i] >> j) & 1: arr[i, j] = 1
    return arr

def solve_S(A_list, B_list):
    rows = []
    for A_mat, B_mat in zip(A_list, B_list):
        A, B = to_np_mat(A_mat), to_np_mat(B_mat)
        for i in range(32):
            for j in range(32):
                row = np.zeros(1024, dtype=np.uint8)
                for k in range(32):
                    if A[k, j]: row[i * 32 + k] ^= 1
                    if B[i, k]: row[k * 32 + j] ^= 1
                rows.append(row)
    
    M = np.array(rows, dtype=np.uint8)
    bit_rows = [sum(int(M[r, c]) << c for c in range(1024)) for r in range(M.shape[0]) if np.any(M[r])]
    
    basis = {}
    for val in bit_rows:
        x = val
        while x:
            lead = x.bit_length() - 1
            if lead in basis: x ^= basis[lead]
            else: basis[lead] = x; break
            
    free_cols = [c for c in range(1024) if c not in basis]
    null_basis = []
    for free in free_cols:
        sol = 1 << free
        for p in sorted(basis.keys()):
            if (sol & basis[p]).bit_count() % 2 != 0:
                sol ^= (1 << p)
        null_basis.append(sol)
        
    for sol in null_basis:
        mat = [[(sol >> (i * 32 + j)) & 1 for j in range(32)] for i in range(32)]
        mat = [sum(mat[i][j] << j for j in range(32)) for i in range(32)]
        if _r(mat) == 32:
            return mat
    return None

def find_key_between_boxes(b1, b2):
    _, basis1 = parse_box(b1)
    _, basis2 = parse_box(b2)
    H1 = [get_mat_from_mask(basis1, genuine_info[b1][0]), get_mat_from_mask(basis1, genuine_info[b1][1])]
    H2 = [get_mat_from_mask(basis2, genuine_info[b2][0]), get_mat_from_mask(basis2, genuine_info[b2][1])]
    
    for tA in [False, True]:
        for tB in [False, True]:
            A0 = _t(H1[0]) if tA else H1[0]
            A1 = _t(H1[1]) if tA else H1[1]
            for order in [(0, 1), (1, 0)]:
                B0 = _t(H2[order[0]]) if tB else H2[order[0]]
                B1 = _t(H2[order[1]]) if tB else H2[order[1]]
                sol = solve_S([A0, A1], [B0, B1])
                if sol is not None:
                    return sol
    return None

groups = {
    16: [49, 60, 82, 86],
    17: [1, 47, 92, 106],
    18: [32, 44]
}

all_keys = []
for m_val, b_list in groups.items():
    used = set()
    for b1, b2 in itertools.combinations(b_list, 2):
        if b1 in used or b2 in used: continue
        S = find_key_between_boxes(b1, b2)
        if S is not None:
            used.add(b1); used.add(b2)
            all_keys.append(S)

key_bytes = _k(all_keys)
cipher = ChaCha20Poly1305(key_bytes)
pt = cipher.decrypt(nonce, ciphertext, _z)
print("FLAG:", pt.decode())
```
