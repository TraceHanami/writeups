# FortID CTF — T9 Multi-Tap Reversing

**Category:** Reverse Engineering  
**CTF Event:** FortID CTF  
**Artifacts:**
- `chall.pyc` (1,154 bytes Python 3.10 bytecode)
- `bytecode.txt` (12,046 bytes pycdc disassembly)  
**Status:** Solved  
**Mechanism:** ITU-T E.161 / T9 Multi-Tap Keystroke Translation  

---

## 1. Challenge Overview

Participants are provided with a Python 3.10 compiled bytecode file `chall.pyc`. Initial attempts to run standard decompilers require Python 3.10 AST support. Decompilation via `pycdc` extracts bytecode disassembly revealing a custom multi-tap keypad parser that validates an encoded sequence against a target hash.

---

## 2. Keypad Mapping Structure

The disassembled bytecode defines the standard numeric keypad mapping:
```python
T9_MAP = {
    '2': 'abc',
    '3': 'def',
    '4': 'ghi',
    '5': 'jkl',
    '6': 'mno',
    '7': 'pqrs',
    '8': 'tuv',
    '9': 'wxyz',
    '0': ' '
}
```

Multi-tap encoding rules:
- Repeating a digit $k$ times selects the $k$-th character on that key (e.g. `2` -> 'a', `22` -> 'b', `222` -> 'c').
- Separators (spaces or short pauses) allow consecutive letters on the same digit key (e.g. `2 22` -> 'ab').
- A space character is generated by pressing `0`.

---

## 3. Disassembly Analysis & Solver

The challenge checks the user's keystroke string, converts it to lowercase text via the multi-tap function, and verifies the SHA-256 digest against the hardcoded target hash.

Reversing the keystroke sequence maps digits directly to the required flag text. Converting the target string according to the keypad dictionary recovers the flag:
```python
def decode_t9(keystrokes):
    result = []
    for token in keystrokes.split():
        if token:
            key = token[0]
            presses = len(token)
            chars = T9_MAP.get(key, '')
            if chars:
                idx = (presses - 1) % len(chars)
                result.append(chars[idx])
    return ''.join(result)
```
Validating the sequence yields the verified flag format `FortID{...}`.
